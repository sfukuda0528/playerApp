# Rich Photo Tab Design

## Goal

写真タブを、ホスト向けのスライドショー情報と全員向けのアップロード状況が分かる画面にする。

## Requirements

- ホストのみ、写真タブ上部にスライドショーを表示する既存挙動を維持する。
- スライドショーには、現在表示中の写真のアップロード時刻を表示する。
- メンバーにはスライドショーを表示しない既存挙動を維持する。
- 写真タブ内に「自分のアップロード枚数」と「全体のアップロード枚数」を表示する。
- 自分の写真一覧と追加ボタンをカード化する。
- 写真追加は複数枚選択に対応する。
- 既存の写真削除、全写真保存、Realtime 連携は維持する。

## Component Design

- `Slideshow` は `Photo.created_at` を現在表示中の写真に合わせて表示する。時刻表示は通常表示と全画面表示の両方で読める位置に置く。
- `PhotoUpload` は `photos` と `currentUserId` から自分の写真数と全体写真数を計算し、カード内に表示する。
- `PhotoUpload` の file input は `multiple` を受け付け、選択された `FileList` を順番に `upload(sessionId, file)` へ渡す。
- アップロード中は選択枚数と進捗をボタン文言に反映する。

## Testing

- `PhotoUpload.test.tsx` に、複数ファイル選択時に各ファイルがアップロードされること、枚数表示、カード内表示を追加する。
- `Slideshow.test.tsx` に、現在写真のアップロード時刻が表示され、自動進行後に時刻も切り替わることを追加する。
