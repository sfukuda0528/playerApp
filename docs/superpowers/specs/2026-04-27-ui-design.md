## カラーパレット

```
Ember Orange  #e07b39  — Primary（ボタン・アクセント）
Bark Brown    #7c4a1e  — Dark（ヘッダー・ナビ・タブバー）
Amber         #c8954a  — Mid（アイコン・強調テキスト）
Cream         #fdf6ec  — Background（ページ背景）
Warm White    #fff8f0  — Surface（カード・入力欄）
Wheat         #f0c896  — Border（罫線・区切り線）
Dark Brown    #3d2003  — Text Primary
Destructive   #c0392b  — 危険操作（セッション終了）
```

`tailwind.config.ts` の `theme.extend.colors` に `camp` キーで定義する。

## 使用する shadcn/ui コンポーネント

- `Button` — Primary / Outline / Destructive バリアント
- `Input` — テキスト入力（URL、ニックネーム、コード）
- `Card` / `CardContent` — フォームラッパー
- `Tabs` / `TabsList` / `TabsTrigger` / `TabsContent` — MainPage タブ
- `Badge` — 参加コード表示

## 画面設計

### TopPage

- 全画面縦中央揃え、背景 `#fdf6ec`
- 上部: 🏕 アイコン + "CampCanvas" ロゴ + キャッチコピー「思い出を、みんなで。」
- ヘッダー背景 `#7c4a1e`、テキスト `#fdf6ec`
- ボタン2本縦並び
  - 「セッション開始」: Primary（`#e07b39`、white テキスト）
  - 「セッションに参加」: Outline（white 背景、`#e07b39` テキスト・ボーダー）

### SessionCreate

- ヘッダー: 「← セッション作成」（`#7c4a1e` 背景）
- 中央に Card
  - ラベル「ニックネーム」+ Input（`#fff8f0` 背景、`#f0c896` ボーダー）
  - Primary Button「セッションを作成」
  - ローディング中は disabled + スピナー

### SessionJoin

- ヘッダー: 「← セッション参加」
- 中央に Card
  - ラベル「6桁コード」+ Input（`letter-spacing: 0.25em`、大きめフォント）
  - ラベル「ニックネーム」+ Input
  - Primary Button「参加する」

### InviteScreen

- ヘッダー: 「メンバーを招待」
- 縦中央: QRコード画像 → Badge（コード、`#f0c896` 背景、`#7c4a1e` テキスト） → 参加人数テキスト → Primary Button「スタート」
- QR は `#fff8f0` 背景の角丸カードに収める

### MainPage

ヘッダー固定（`#7c4a1e`）: 「🏕 CampCanvas」 + 右端に「👥 N/4」バッジ  
下部固定タブバー（`#7c4a1e`）: 写真 / 音楽 / メンバー（アクティブ時 `#e07b39` アンダーライン）

#### 写真タブ（全ユーザー表示、スライドショーはホストのみ）

- **ホスト**: スライドショー（`#c8954a` 背景プレースホルダー、角丸なし全幅）→ 写真追加ボタン → 自分のアップロード写真サムネイル一覧（削除ボタン付き）
- **参加者**: スライドショー非表示。写真追加ボタン → 自分のアップロード写真サムネイル

#### 音楽タブ（全ユーザー）

- プレイヤーエリア（`#3d2003` 背景）: 曲名 → ⏮ ⏸/▶ ⏭ コントロール
- 「キュー」ラベル（`#c8954a`）
- キューリスト: 再生中は `#e07b39` 背景ハイライト、それ以外は `#fff8f0` + `#f0c896` ボーダー
- 各アイテム右端に削除ボタン（自分が追加したもののみ）
- 最下部に「+ YouTube URL を追加」ダッシュボーダーボタン → Input展開

#### メンバータブ

- **ホスト**: QRコード（`#fff8f0` カード）→ Badge（コード）→ 参加人数 → 「＋メンバー追加」ボタン（Primary） → 「セッション終了」ボタン（Destructive）
- **参加者**: 参加人数のみ表示（QR・コード・ボタン類は非表示）

**JoinOverlay は廃止**。メンバータブに統合するため `JoinOverlay.tsx` は削除対象。

## セットアップ手順（実装時）

1. `npm install tailwindcss @tailwindcss/vite` → `vite.config.ts` に plugin 追加
2. `index.css` を `@import "tailwindcss"` に置き換え
3. `npx shadcn@latest init` → `tailwind.config.ts` にカラートークン追加
4. `npx shadcn@latest add button input card tabs badge`
5. 各コンポーネントにスタイル適用
