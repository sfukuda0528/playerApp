# 要件定義書

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | CampCanvas（キャンプキャンバス） |
| コンセプト | グランピングの空気感を引き立てるリアルタイム・フォトウォール・アプリ |
| 主な利用シーン | グランピング中、複数人がスマートフォンで撮影した写真をメインディスプレイに即時反映 |
| 対象ユーザー | グランピング参加者（4人程度のグループ） |

---

## 機能要件一覧

| ID | 要件名 | 説明 | 優先度 | 出典 |
|----|--------|------|--------|------|
| FR-001 | リアルタイム写真アップロード | スマートフォンから写真を撮影・アップロードできる | High | Key Features |
| FR-002 | リアルタイム・フォトウォール同期 | アップロードされた写真をラグなしでメインのスライドショーに反映 | High | Key Features |
| FR-003 | スライドショー表示 | タブレット・PC側でスライドショーとして写真を表示 | High | Key Features |
| FR-004 | 音楽アップロード | メンバーが音楽ファイルをアップロードしてプレイリストに追加 | High | Key Features |
| FR-005 | アンビエント・プレイヤー | アップロード音楽と環境音（焚き火・森林音等）をミックス再生 | High | Key Features |
| FR-006 | 環境音ライブラリ | 焚き火・森林音など複数の環境音をプリセットとして提供 | Medium | Key Features |
| FR-007 | モーメント・ログ生成 | 旅行終了後、写真と再生プレイリストを「思い出の記録」として自動まとめ | Medium | Key Features |
| FR-008 | マルチトラック同時再生 | 音楽と環境音を同時・独立して再生制御 | High | Tech Stack（Howler.js） |
| FR-009 | セッション管理 | グループ単位でセッション（部屋）を作成・参加できる | High | Concept（4人の仲間） |
| FR-010 | レスポンシブUI | スマートフォン〜タブレット・PC各デバイスで最適な画面を提供 | High | Tech Stack（Tailwind CSS） |

---

## 非機能要件一覧

| ID | 区分 | 要件名 | 説明 | 優先度 |
|----|------|--------|------|--------|
| NFR-001 | リアルタイム性 | 写真同期レイテンシ | アップロードからスライドショー反映まで体感ラグなし（目安: 2秒以内） | High |
| NFR-002 | 可用性 | Supabase依存可用性 | Supabase Realtimeの稼働率に依存。SLA範囲内での継続稼働 | Medium |
| NFR-003 | スケーラビリティ | 同時接続数 | 小規模グループ（4〜10人程度）の同時接続を安定サポート | Medium |
| NFR-004 | パフォーマンス | 音声再生品質 | Howler.js（Web Audio API）によるマルチトラック再生の途切れなし | High |
| NFR-005 | セキュリティ | ファイルアクセス制御 | Supabase Storage・DBへのアクセスをセッション単位で制限 | High |
| NFR-006 | 保守性 | 型安全 | React + TypeScriptによる型安全な実装 | Medium |
| NFR-007 | ビルド速度 | 開発体験 | Viteによる高速HMRで開発効率確保 | Low |
| NFR-008 | データ永続性 | ログ保存 | モーメント・ログはSupabase DB（PostgreSQL）に永続保存 | Medium |
| NFR-009 | ファイルストレージ | 写真・音楽容量 | Supabase Storageの無料枠・有料枠範囲内での運用設計 | Medium |

---

## 制約・前提条件

| ID | 内容 |
|----|------|
| CON-001 | フロントエンドは React + TypeScript + Vite で実装 |
| CON-002 | バックエンドはSupabase（BaaS）のみ使用。独自サーバー構築なし |
| CON-003 | リアルタイム同期はSupabase RealtimeのWebSocketを利用 |
| CON-004 | 音声再生はHowler.js（Web Audio API）に限定 |
| CON-005 | スタイリングはTailwind CSSのみ使用 |
| CON-006 | 対応デバイスはスマートフォン（アップロード用）とタブレット・iPad・PC（表示用）の2役割 |
| CON-007 | 想定同時利用人数は4人程度（小規模グループ向け） |

---

## 未確認事項

詳細は `open_questions.md` 参照。

主な未確認項目:
- セッション（部屋）の作成・参加フロー
- 写真・音楽ファイルの容量・フォーマット制限
- モーメント・ログのエクスポート手段
- 環境音のプリセット種類・数
- 音量バランス（音楽vs環境音）の制御UI
