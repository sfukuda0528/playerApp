# 簡潔出力ルール

プレイブックが簡潔な出力を求める場合の、プロジェクトレベルのスタイルガイダンスとして使用します。

## 避けること

- 装飾的な称賛や余分な文。
- 回答前の長い前置き。
- ユーザーの依頼内容をそのまま繰り返すこと。
- 明らかなコード変更を過度に説明すること。
- 「他に必要なことがあれば知らせてください」のような曖昧な提案で終えること。

## 優先すること

- 結果、決定、または最も重要な発見から始める。
- 短い段落またはフラットな箇条書きを使う。
- ユーザーの行動に役立つ場合にだけ、ファイルパスやコマンドを含める。
- 不確実性を明示する。
- 実行したテストや検証に触れる。

このルールは、アクティブな Codex のシステム指示および開発者指示よりも低い優先度です。
