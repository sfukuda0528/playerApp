# CampCanvas (キャンプキャンバス)

グランピングの「今」を、最高の演出で共有するリアルタイム・フォトウォール・アプリ。

## 🌟 Concept
「豪華なキャンプ」であるグランピングの空気感を壊さず、むしろ引き立てるためのデジタル・オーナメント。
4人の仲間がそれぞれのスマートフォンで撮影した写真が、メインディスプレイ（タブレットやPC）のスライドショーに即座に反映され、その場のBGMと共に大切な時間を彩ります。

## ✨ Key Features
- **リアルタイム・同期フォトウォール**: メンバーがアップロードした写真が、ラグなしでメインのスライドショーに差し込まれます。
- **アンビエント・プレイヤー**: スライドショーの背後で、メンバーがアップロードした音楽プレイリストと焚き火や森林音の環境音をミックスして再生。
- **モーメント・ログ**: 旅行終了後、アップロードされた写真と再生されていた曲のプレイリストを「思い出の記録」として自動的にまとめます。

## 🛠 Tech Stack

### Frontend
| 技術 | 用途 |
|------|------|
| React + TypeScript | UIコンポーネント・型安全 |
| Vite | ビルドツール・高速HMR |
| Tailwind CSS | レスポンシブスタイリング（スマホ〜タブレット対応） |
| Howler.js | BGM・環境音のマルチトラック同時再生（Web Audio API） |

### Backend / BaaS
| 技術 | 用途 |
|------|------|
| Supabase Realtime | WebSocketによるリアルタイム写真同期 |
| Supabase Storage | 写真・音楽ファイルのアップロード・配信 |
| Supabase DB (PostgreSQL) | モーメントログ・プレイリスト永続化 |

### 対応デバイス
- スマートフォン（写真・音楽アップロード用）
- タブレット・iPad・PC（メインディスプレイ／スライドショー表示用）
