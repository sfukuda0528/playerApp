# 機能要件詳細

## FR-001: リアルタイム写真アップロード

| 項目 | 内容 |
|------|------|
| ID | FR-001 |
| 要件名 | リアルタイム写真アップロード |
| 優先度 | High |
| 概要 | スマートフォンのカメラで撮影した写真、またはカメラロールの写真をアップロードできる |
| 詳細 | - デバイスのカメラ起動またはギャラリー選択でファイル取得<br>- 選択後、Supabase Storageへアップロード<br>- アップロード完了後、Supabase Realtimeで他メンバーに通知 |
| 前提 | セッションに参加済みであること |
| 未確認 | 対応ファイル形式（JPEG/PNG/HEIC等）、最大ファイルサイズ |

---

## FR-002: リアルタイム・フォトウォール同期

| 項目 | 内容 |
|------|------|
| ID | FR-002 |
| 要件名 | リアルタイム・フォトウォール同期 |
| 優先度 | High |
| 概要 | アップロードされた写真をラグなしでメインのスライドショーに反映する |
| 詳細 | - Supabase RealtimeのWebSocketでアップロードイベントを受信<br>- 受信した写真URLをスライドショーキューに挿入<br>- 目標レイテンシ: 2秒以内 |
| 前提 | メインディスプレイ側がセッションに参加・接続中であること |
| 未確認 | キュー管理方法（FIFO/ランダム挿入等）、写真枚数上限 |

---

## FR-003: スライドショー表示

| 項目 | 内容 |
|------|------|
| ID | FR-003 |
| 要件名 | スライドショー表示 |
| 優先度 | High |
| 概要 | タブレット・PC側でアップロード済み写真をスライドショー形式で表示 |
| 詳細 | - 写真を一定間隔で切り替えて表示<br>- 新規アップロード写真は優先的に（または次の順番で）表示<br>- グランピングの雰囲気に合ったアニメーション・トランジション |
| 前提 | 1枚以上の写真がアップロード済みであること |
| 未確認 | スライド切り替え間隔（固定 or ユーザー設定可）、トランジション種類 |

---

## FR-004: 音楽アップロード

| 項目 | 内容 |
|------|------|
| ID | FR-004 |
| 要件名 | 音楽アップロード |
| 優先度 | High |
| 概要 | メンバーが音楽ファイルをアップロードし、セッションのプレイリストに追加できる |
| 詳細 | - デバイスのファイルから音楽ファイルを選択<br>- Supabase Storageへアップロード<br>- Supabase DBのプレイリストテーブルにレコード追加<br>- アンビエント・プレイヤーへリアルタイム反映 |
| 前提 | セッションに参加済みであること |
| 未確認 | 対応フォーマット（MP3/AAC/FLAC等）、最大ファイルサイズ、著作権対応方針 |

---

## FR-005: アンビエント・プレイヤー

| 項目 | 内容 |
|------|------|
| ID | FR-005 |
| 要件名 | アンビエント・プレイヤー |
| 優先度 | High |
| 概要 | メンバーアップロード音楽と環境音をミックスしてスライドショー背後で再生 |
| 詳細 | - Howler.js（Web Audio API）でマルチトラック同時再生<br>- 音楽トラック: アップロードされた音楽をプレイリスト順に再生<br>- 環境音トラック: 選択中の環境音をループ再生<br>- 各トラックの音量を独立制御 |
| 前提 | メインディスプレイ側で動作。ブラウザの自動再生ポリシー対応が必要 |
| 未確認 | 初回再生のトリガー（ユーザー操作必須 or 自動）、クロスフェード有無 |

---

## FR-006: 環境音ライブラリ

| 項目 | 内容 |
|------|------|
| ID | FR-006 |
| 要件名 | 環境音ライブラリ |
| 優先度 | Medium |
| 概要 | 焚き火・森林音など複数の環境音をプリセットとして提供・選択できる |
| 詳細 | - プリセット環境音リストをUI上に表示<br>- 1種類を選択してループ再生<br>- 「なし」選択で環境音を無効化 |
| 前提 | 環境音ファイルはアプリ同梱またはSupabase Storage配置 |
| 未確認 | プリセット種類・数（焚き火・雨・森・波等）、ファイル形式・ビットレート |

---

## FR-007: モーメント・ログ生成

| 項目 | 内容 |
|------|------|
| ID | FR-007 |
| 要件名 | モーメント・ログ生成 |
| 優先度 | Medium |
| 概要 | 旅行終了後、アップロード写真と再生プレイリストを「思い出の記録」として自動まとめ |
| 詳細 | - セッション終了操作をトリガーに生成<br>- 写真一覧（サムネイル）と再生曲リストをSupabase DBに保存<br>- 生成済みログを後から閲覧できる |
| 前提 | セッション中のアップロードデータがSupabase DBに記録済みであること |
| 未確認 | ログのエクスポート機能（PDF/画像共有等）の有無、保存期間・削除ポリシー |

---

## FR-008: マルチトラック同時再生

| 項目 | 内容 |
|------|------|
| ID | FR-008 |
| 要件名 | マルチトラック同時再生 |
| 優先度 | High |
| 概要 | 音楽トラックと環境音トラックを独立して同時再生・制御できる |
| 詳細 | - Howler.jsで複数Howlインスタンスを生成<br>- 音楽・環境音それぞれの音量スライダー提供<br>- 一方を停止しても他方に影響しない |
| 前提 | Web Audio API対応ブラウザ（モダンブラウザ全般） |
| 未確認 | モバイルブラウザでの音量制御制限（iOS Safari等） |

---

## FR-009: セッション管理

| 項目 | 内容 |
|------|------|
| ID | FR-009 |
| 要件名 | セッション管理 |
| 優先度 | High |
| 概要 | グループ単位のセッション（部屋）を作成・参加・終了できる |
| 詳細 | - セッション作成: ホストがセッションを生成し、参加コード/URLを発行<br>- セッション参加: 参加コード/URLでメンバーが入室<br>- セッション終了: ホストが終了操作を行いモーメント・ログ生成をトリガー<br>- セッションIDをSupabase DBに保存 |
| 前提 | 認証は最小限（匿名認証または名前入力のみ）でよい可能性あり |
| 未確認 | 認証方式、最大参加人数、セッション有効期限 |

---

## FR-010: レスポンシブUI

| 項目 | 内容 |
|------|------|
| ID | FR-010 |
| 要件名 | レスポンシブUI |
| 優先度 | High |
| 概要 | スマートフォン（アップロード用）とタブレット・PC（表示用）で最適なUIを提供 |
| 詳細 | - Tailwind CSSのブレークポイントでレイアウト切り替え<br>- スマートフォン: 写真・音楽アップロードに特化したUI<br>- タブレット・PC: フルスクリーンのスライドショー・プレイヤーUI |
| 前提 | モダンブラウザのみ対応（ネイティブアプリ不要） |
| 未確認 | スマートフォンでもスライドショー表示するか否か |
